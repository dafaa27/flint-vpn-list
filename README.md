# 🌐 Flint VPN List

Список доменов и IPv4-подсетей для выборочного VPN на GL.iNet Flint 2.

🔄 Обновляется ежедневно около 06:17 МСК. Роутер обновляет подписку отдельно.

## 🔗 Подписка

https://raw.githubusercontent.com/dafaa27/flint-vpn-list/main/vpn-list.txt

Режим: **Specified Domain / IP List**. Остальное: **Allow Non-VPN Traffic**.

## 🙌 Источники и благодарности

- [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains) — домены и подсети.
- [DanielLavrushin/b4geoip](https://github.com/DanielLavrushin/b4geoip) — источники дополнительных сетей.
- [GitHub API](https://api.github.com/meta) и [RIPEstat](https://stat.ripe.net/) — сетевые данные.

💡 Дополнительные списки найдены через [Forkop X](https://github.com/Screamshow/forkop-x) и [b4geoip-forkop](https://github.com/Greeg0ry/b4geoip-forkop); их код не используется.

📝 Неофициальная сборка. Применяются условия источников; указание авторства не заменяет разрешение на распространение.
