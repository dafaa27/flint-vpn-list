Automatically updated domains and IPv4 networks for selective
VPN routing on GL.iNet Flint 2.

## Sources & credits

- [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains)
  — selected categories, service domains and IPv4 lists.
  Credit: itdoginfo and contributors.
- [DanielLavrushin/b4geoip](https://github.com/DanielLavrushin/b4geoip)
  — configuration of GitHub, Bungie, Sony and Ubisoft network sources.
  Credit: DanielLavrushin and contributors. Upstream license: MIT.
- [GitHub Meta API](https://api.github.com/meta) and
  [RIPEstat](https://stat.ripe.net/) — network data.

Additional categories were discovered through
[Forkop X](https://github.com/Screamshow/forkop-x) and
[b4geoip-forkop](https://github.com/Greeg0ry/b4geoip-forkop).
Their code and SRS files are not used.

## Subscription

https://raw.githubusercontent.com/dafaa27/flint-vpn-list/main/vpn-list.txt

GL.iNet: **Specified Domain / IP List → Subscription URL**.
Other traffic: **Allow Non-VPN Traffic**.

The file is scheduled to update daily at 06:17 Moscow time.
Router refresh is configured separately.
